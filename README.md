# Coco Skills

Personal, independent Codex skills for requirement analysis, defect investigation, change control, planning, implementation, verification, and delivery.

## Skills

Each `coco-*` directory is an independently installable skill containing `SKILL.md` and optional `agents/`, `references/`, or `scripts/` resources.

## Install

Install a skill into the local Codex skills directory with the Codex skill installer, using this repository and the desired `coco-*` path.

## Codebase index

`coco-codebase-index` provides a local, incremental index for navigation and impact analysis. The index itself is generated under a target project and should not be committed here.
